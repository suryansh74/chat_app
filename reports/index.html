API Endpoints

RESTful API with authentication

Method Endpoint Auth Description
POST /api/auth/register None Register new user
POST /api/auth/login None Login with credentials
POST /api/auth/logout Required Logout and clear cookie
GET /api/profile Required Get user profile
POST /api/email_verification/send_otp Required Send OTP for verification
POST /api/email_verification/verify_otp Required Verify OTP and mark verified
GET /api/email_verification/verified Required Check if email verified
POST /api/password_reset/send_otp None Send password reset OTP
POST /api/password_reset/verify_otp None Verify password reset OTP
POST /api/password_reset/set_password None Set new password

Database Schema

MySQL with GORM

Users Table

Column Type Constraints Description
id VARCHAR(36) PRIMARY KEY UUID
name VARCHAR(100) NOT NULL User's full name
email VARCHAR(255) UNIQUE, NOT NULL User's email
password VARCHAR(255) NOT NULL Bcrypt hashed
is_verified BOOL DEFAULT FALSE Email verified status
otp VARCHAR(6) NULL Verification OTP
otp_expiry DATETIME NULL OTP expiration
password_reset_otp VARCHAR(6) NULL Password reset OTP
created_at DATETIME AUTO Creation timestamp

Password Reset Flow

HttpOnly Cookies

Tokens stored in HttpOnly cookies, inaccessible to JavaScript

OTP Expiry
